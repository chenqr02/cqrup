# cqrup

Personal website for Qirui Chen, built from the [al-folio](https://github.com/alshedivat/al-folio) academic homepage starter.

- **GitHub Pages:** <https://chenqr02.github.io/cqrup/>
- **Source:** <https://github.com/chenqr02/cqrup>

The navigation keeps the familiar academic structure—News, Publications, Creator Path, and CV—while clearly separating academic records from Bilibili uploads.

## Edit the site

- Biography and homepage: `_pages/about.md`
- Academic bibliography: `_bibliography/papers.bib`
- Creator timeline: `_pages/creator-path.md`
- Bilibili publication metrics: `_pages/publications.md`
- News: `_news/`
- CV: `_data/cv.yml`

Bilibili metrics are dated snapshots and may change. Academic publications and media uploads are shown in separate sections.

GitHub Actions deploys changes from `main` to the `gh-pages` branch.
